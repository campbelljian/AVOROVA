# Codex 兼容性与验证记录

[返回项目首页](../README.md) · [English](COMPATIBILITY.en.md)

**没在表里看到自己的版本？不代表不能用。** Codex 在开发期间更新频繁，AVOROVA 持续做了多轮兼容适配。这里列出的是实际验证过的版本及范围，并非兼容白名单；未列出的版本也可能正常使用。

截至 2026-10-30，现有记录覆盖至少 **17 个 Codex Windows 商店包版本**的真实运行测试。它们包含分项自动实测和用户实机验收，测试范围各不相同；历史记录对应当时的 AVOROVA，不能理解为当前版本已对所有旧版重新完整测试。

脑洞的“返回原窗口查看”不等于精确定位到任意历史消息，精确定位仍需继续适配。新 Codex 版本可能影响部分功能，我们会持续跟进；遇到问题可附版本和复现步骤联系 [8849412@qq.com](mailto:8849412@qq.com)。

## 为什么不只按版本号判断？

AVOROVA 的主题启动链会检查实际模块与窗口结构，并非只允许上表这些数字。但 Codex 的内部结构可能随更新变化，部分功能仍需单独适配。因此，没有列出的版本可以尝试使用；如果某项功能表现异常，欢迎反馈帮助我们补充验证。

Codex++ 的历史共存记录也不是对所有 Codex++ 版本或中转服务的统一保证。服务与模型可用性取决于用户自己的配置和服务提供方；AVOROVA 暂不显示中转站余额。
