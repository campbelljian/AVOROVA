# Codex 兼容性说明

[返回项目首页](../README.md) · [English](COMPATIBILITY.en.md)

**没在表里看到自己的版本？不代表不能用。** Codex 在创作过程中更新频繁，AVOROVA 已持续进行了多轮兼容适配。下表是实际验证过的版本记录，并非仅支持这些版本的名单；未列出的版本也可能正常使用。

截至 2026-10-30，现有记录覆盖至少 **17 个 Codex Windows 商店包版本**。各版本验证的功能范围不同，历史记录对应当时的 AVOROVA，不表示当前版本已对全部旧版重新完整测试。

## 最近验证的 Codex 版本

| 版本名称 | 版本号 |
| --- | --- |
| Codex 应用版本 | **26.1027.30824** |
| 对应 Windows 商店包版本 | **26.1027.3384.0** |

这两个编号属于同一个 Codex 安装包，只是编号规则不同。

已验证的功能包括主题启动、视频播放与暂停、输入框显示、脑洞记录保留、用户及助手消息摘录保存、摘录复制、返回原窗口，以及内置终端显示与输入。玻璃透明效果可能受图形环境影响，部分环境可能出现黑色背景。

脑洞的“返回原窗口查看”不等于精确定位到任意历史消息。新 Codex 版本也可能影响个别功能，我们会持续跟进；遇到问题可附版本和复现步骤联系 [8849412@qq.com](mailto:8849412@qq.com)。
