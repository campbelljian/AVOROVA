# 常见问题

[返回项目首页](../README.md) · [English](FAQ.en.md)

## 现在可以下载安装吗？

还不可以。当前是发布准备阶段，本仓库仅提供产品介绍、预览图片和演示动图，没有安装包或可执行文件。经过验证的安装、更新步骤会与安装包一起发布。

## 官网打不开怎么办？

部分代理节点或分流设置可能导致官网连接异常。如果出现连接被关闭、长时间无响应等情况，可以尝试：

1. 在代理软件中，将 `avorova.app` 和 `www.avorova.app` 设置为直连（DIRECT），然后重新打开官网。
2. 或暂时关闭代理，再访问 [avorova.app](https://avorova.app/?utm_source=github) 做对比。

如果仍然无法打开，可换一个网络或代理节点重试，并保留浏览器名称、错误提示及直连与代理访问的对比结果，便于后续排查。

## 安装时出现防护提示怎么办？

目前测试安装包尚未添加 Windows 代码签名，Windows 可能显示“未知发布者”或信誉提示。微软说明，签名状态、发布者信誉和文件信誉都会影响 SmartScreen 判断，即使已签名的新程序也可能出现提示。[微软关于 SmartScreen 信誉的说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。

信誉提示不等于已经检测到病毒，也不能证明文件安全。请核对文件来源；若明确报告病毒或木马，请暂停安装，保留防护软件名称、检测名称、文件版本及提示截图供核查，不要直接忽略或关闭防护。

AVO 当前换肤功能不改写 Codex 原始安装文件；主题效果在运行时加载。正式安装包的签名状态和校验信息以对应版本的发布说明为准。

## 它适用于什么产品？

AVOROVA 面向 Windows 上的 ChatGPT 桌面应用 / Codex，提供主题、皮肤与换肤美化功能。OpenAI 当前将桌面应用称为 ChatGPT，应用内仍提供 Codex；可以查看[官方桌面应用说明](https://learn.chatgpt.com/docs/app)和 [Windows 版本说明](https://learn.chatgpt.com/docs/windows/windows-app)。

这里的主题与操作演示围绕桌面应用中的 Codex 界面展开。AVO 不属于 chatgpt.com 网页换肤扩展。具体支持哪些 Windows 和桌面应用版本，会在正式发布说明中列出；当前不承诺支持所有版本。

## 中转站用户可以使用吗？

可以。AVO 提供 Codex 主题模式与 Codex++ 模式，通过 Codex++ 使用中转服务的用户也能使用主题美化。

使用中转服务时，先另行安装 Codex++，并在其中配置好服务地址、密钥及可用模型，再在 AVO 中选择 Codex++ 模式启动。服务与模型的可用性取决于 Codex++ 和所用中转服务；AVO 不提供中转服务或 API 额度。普通 Codex 主题模式无需安装 Codex++。

额度电池显示 Codex 套餐额度，暂不显示中转站余额。

## 主题有哪几类？

主题库目前按视频、图片、动效、玻璃等类型展示。README 顶部的动图展示三款主题放进完整 Codex 窗口的效果；静态大图方便查看界面细节。

## 这些动图可以直接操作吗？

不能。它们是录自官网界面演示的短循环动图，并非实际桌面录屏，也不会在 GitHub 页面运行主题。脑洞和额度电池的动图用于介绍操作流程，里面的对话和额度是示例数据。

## 脑洞怎么用？

在 Codex 对话里选中文字，点击“存入脑洞”，可以接着写笔记、粘贴图片，内容自动保存在本机。已有笔记也可以从顶栏的脑洞入口查看。能够定位原消息时，可返回原对话查看上下文。

## 额度电池会增加额度或自动使用重置卡吗？

不会。它显示 Codex 账号提供的套餐剩余额度、恢复时间和重置卡数量，属于只读信息展示，不增加额度，也不执行重置。暂不显示中转站余额。

## 为什么预览里写着 74%、63% 和 ×2？

这些是用于介绍界面的示例数据，不代表任何用户的真实账号状态，也不是产品承诺提供的额度。

## 网页上选好主题，就一定能直接应用吗？

网页应用入口需要本机安装支持该能力的 AVO 版本，并完成相应的协议注册；浏览器还可能要求确认打开 AVO。正式安装包尚未发布，这条完整的安装与应用流程还需要随发布版本完成验收。

## 可以上传自己的主题到社区吗？

目前没有开放主题社区，也没有开放社区投稿入口。

## 这个仓库会公开程序源码吗？

本仓库用于产品介绍、使用说明和后续版本发布资料，不提供 AVO 主程序源码或 Codex 源码。

## AVOROVA 是 OpenAI 官方产品吗？

不是。AVOROVA 是独立项目，与 OpenAI 没有隶属关系，也未获得其官方背书。
