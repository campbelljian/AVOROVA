# AVOROVA V6.0.3 · 软件内更新 / In-app update

[简体中文](#简体中文) · [English](#english)

## 简体中文

**V6.0.3 已通过正常软件内更新通道发布。** 本次调整部分已有聊天页面的主题宿主识别，处理页面合法但主题未能正确绑定的问题。

新用户请先下载 [V6.0.2 独立安装包](https://github.com/campbelljian/AVOROVA/releases/download/v6.0.2/AVOROVA-Setup-V6.0.2.exe)，再在 AVO 中检查更新。独立安装包版本仍为 V6.0.2；[安装与 SHA256 校验](RELEASE-V6.0.2.md)。

更新步骤：

1. 在 AVO 设置中选择“检查更新”，按界面提示下载 V6.0.3。
2. 选择“下次启动时更新”后，从托盘正常退出 AVO。
3. 从原桌面入口重新打开，更新完成后查看版本 V6.0.3。

本次相对 V6.0.2 替换 22 个程序文件，没有新增或删除程序文件。主题、设置和原本地记录保留。脑洞界面、划词采集及摘录／来源跳转已自 V6.0.2 取消，旧记录不删除；主题、额度电池和官方公告显示继续保留。

这是正常更新，不要求手工替换 DLL。界面显示版本为 V6.0.3，底层版本为 6.0.3.0。有关玻璃显示的历史边界见[兼容性说明](COMPATIBILITY.zh-CN.md)。

## English

**V6.0.3 is available through the normal in-app update channel.** It adjusts theme-host recognition for some existing-chat pages whose valid workspace was not being bound correctly.

New users should first download the [V6.0.2 standalone installer](https://github.com/campbelljian/AVOROVA/releases/download/v6.0.2/AVOROVA-Setup-V6.0.2.exe), then check for updates inside AVO. The standalone installer remains V6.0.2. [Setup and SHA256 verification](RELEASE-V6.0.2.md#english).

To update:

1. Check for updates in AVO settings and download V6.0.3 as prompted.
2. Choose to install on the next launch, then exit AVO normally from the tray.
3. Reopen it from the existing desktop shortcut and confirm V6.0.3 after updating.

Compared with V6.0.2, this update replaces 22 program files with no program-file additions or removals. Themes, settings, and existing local records are retained. Brainstorm, text capture, excerpts, and source navigation were removed starting with V6.0.2; old records are retained. Themes, the quota battery, and official announcement display remain available.

This is a normal update; no manual DLL replacement is required. The displayed version is V6.0.3 and the underlying version is 6.0.3.0. See the [compatibility notes](COMPATIBILITY.en.md) for historical glass-rendering boundaries.
